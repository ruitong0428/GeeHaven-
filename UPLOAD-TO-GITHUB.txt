上传方法
1. 先解压 ZIP。不要直接把 ZIP 文件上传到 GitHub 当作网页。
2. 打开你现有的网站仓库，上传解压后的全部文件和文件夹，覆盖同名文件。
   保持 admin、assets、css、js、supabase 这些文件夹的结构。
3. 确认仓库首页可以直接看见 index.html、menu.html、admin、assets、js。
   不要在它们外面再放一层 Gee-Haven-Fixed-v7 或 Gee-Haven-Complete 文件夹。
4. 如果发布源是仓库根目录：Settings → Pages → Build and deployment，
   Source 选 Deploy from a branch，选择存放这些文件的分支，文件夹选 /(root)，
   点击 Save。如果原本配置的是 /docs，则把全部文件放进 docs 文件夹内。
5. 等待 Pages 部署成功，打开 Settings → Pages 显示的网站地址。
   如仍看到旧页面，按 Ctrl+F5 强制刷新。
